# Brisk 1.7.3

### Fixed

- **The window could open larger than the screen it opened on.** Its size was
  worked out from the display the mouse pointer happened to be on, while it was
  centred on the main display. When those are two different screens — a wide
  monitor next to a small laptop panel, say — the window was measured for one
  and placed on the other, and the right-hand side ran off the edge.

  It now opens centred on the same screen its size was measured for, so it fits
  wherever you are working.
