# Brisk 1.6.3

**Worth installing.** This is the release that makes every release after it
reach you on time.

### Fixed

- **Brisk now looks for a new version every time it starts.** The check used to
  be skipped unless twenty hours had passed since the last successful one, so a
  release could sit unnoticed for most of a day — including a release that fixed
  something you were waiting for.

  It is one small text file fetched on a background thread, so start-up is just
  as fast as before. Nothing is downloaded and nothing is installed without you
  saying so first, and what does get downloaded is still checked against the
  checksum in the version file before anything runs.

  You can still force a check at any time with **Check for update** under
  Maintenance, and turn the automatic one off entirely by setting
  `SjekkAutomatisk` to `0` under `HKCU\Software\Brisk`.
