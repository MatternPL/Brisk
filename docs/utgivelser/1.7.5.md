# Brisk 1.7.5

### Fixed

- **Installing Brisk left an unsigned copy on your machine.** The download was
  signed, and so was the standalone `Brisk.exe` on the release page — but the
  installer carries the program inside itself, and it was packed in one step
  before it was signed. What ended up in `%LOCALAPPDATA%\Programs\Brisk` was
  therefore the copy without a signature. Right-clicking it and opening
  Properties showed an empty *Digital Signatures* tab, and Windows said
  *Unknown publisher* whenever Brisk asked for administrator.

  This was true of every signed release so far, 1.7.0 through 1.7.4. Update to
  this one and the installed program carries the signature it should have had
  from the start. Nothing else about those releases was wrong: the files you
  downloaded were signed, and the checksums published for them were correct.

  The program is now signed before it is packed in, and the release build
  unpacks the installer and refuses to publish if the copy inside is unsigned —
  so the order cannot quietly go wrong again.
