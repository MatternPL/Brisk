# Brisk 1.5.0

Startup: turning off a scheduled task looked like it did nothing. The task was switched off in Windows, but the row kept its old status, so there was no way to tell. Startup also failed to read the program path for nine entries - shortcuts, batch files and values with doubled quotes - which left the publisher blank for them. Entries pointing at programs that are no longer installed are now marked in red; they start nothing and are safe to switch off. The Delays startup column showed an empty cell for most rows. Windows only measures programs it thinks noticeably slow startup, so a dash now says it has never measured that one.
