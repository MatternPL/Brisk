# Brisk 1.5.0

### Fixed

- **Turning off a scheduled task looked like it did nothing.** The task was
  switched off in Windows, but the row kept its old status, so there was no way
  to tell it had worked. If you tried this before, those tasks really are off.
- **Startup could not read the program path for nine entries** — shortcuts, batch
  files, and values with doubled quotes. Those rows had no publisher and no way
  to check the program. All of them read correctly now.

### New

- **Entries pointing at programs that are no longer installed are marked in red.**
  They start nothing and are safe to switch off. On the machine this was built on,
  five of them were left behind by uninstalled software.

### Changed

- **The "Delays startup" column now shows a dash instead of an empty cell.**
  Windows only measures programs it thinks noticeably slow startup, so most rows
  have never been measured. A blank looked like something was broken; a dash and
  a line under the list say what it means.
