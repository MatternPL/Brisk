# Brisk 1.7.2

### Fixed

- **The interface broke on scaled displays.** On a screen set to 125% or 150% —
  which is the default on most laptops — text ran past the boxes drawn for it,
  slid underneath the lines below, and buttons came out too small for their own
  labels.

  The manifest promised Windows that Brisk scaled itself. It did not: every
  position is a fixed pixel value, while the fonts are given in points and grow
  with the display scaling. At 125% a line of small text needs 18.8 pixels in a
  box built for 18; at 150% it needs 22.6. Brisk no longer makes that promise,
  so Windows scales the window instead, and the layout holds at any scaling.
  The trade is slightly softer text above 100%, which is the better half of the
  bargain.

- **Virtualisation-based security said "restart to apply" when a restart could
  never help.** On some machines VBS keeps running no matter what is turned
  off, and Brisk kept promising the next restart would fix it.

  It now looks for the actual reason first and says it. The common one is
  Windows Hello: enhanced sign-in security runs the biometric part inside VBS
  and ignores every switch meant to turn VBS off. Where that is the cause, the
  *Force off* button is gone as well — it changes the boot configuration, and
  measured on such a machine, that setting was already off while VBS ran
  anyway. A button that cannot do its job is worse than no button.

  If no known reason is found, Brisk says that instead of guessing.
