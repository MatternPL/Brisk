# Brisk 1.6.6

### New

- **A Screen page.** Every screen is listed by its own name, read from the
  screen rather than the driver, with its size, year, resolution and what it
  runs at — next to the fastest it can do at that resolution. A panel bought
  for 144 or 240 Hz sitting at 60 is the most commonly wasted performance
  there is, and it takes one button to fix. The mode is tried without saving
  first, so a setting the screen cannot take is refused rather than leaving
  you with a black display.

- **Colour, with a real undo.** Deeper blacks and a little more saturation.
  Whether it looks better is a matter of taste, so try it. Brisk reads the
  gamma curve you have now before it changes anything, so Reset puts back
  exactly what you had — a calibrated screen keeps its calibration. Saturation
  needs NVIDIA's own library; the gamma curve works on any graphics card.

- **Three NVIDIA settings under Games:** driver power management, shader cache
  and low latency. They are read and written through the driver's own settings
  store, the same one the NVIDIA control panel uses, and Undo removes the
  setting so NVIDIA's default applies again rather than a guess at what it is.

  AMD has no public equivalent, so on an AMD card these three do not exist at
  all rather than sitting there greyed out. The Screen page works on both.

- **Xbox Game Bar** is back on the Games page, doing the only thing that
  actually stops Windows+G: uninstalling the app. It asks first, and Undo
  opens the Store page.

### Fixed

- **The front page could open empty.** The numbers were set in a job that only
  runs once the window is already up, so on a busy machine you could be
  looking at dashes in every card. They are set before the window is drawn now.

- **Virtualisation-based security said "restart to apply" forever,** including
  long after the restart. It now compares when the change was made against
  when the machine last booted. Where Windows starts it anyway — which happens,
  registry or not — it says so, and offers to force the hypervisor off in the
  boot configuration. That names what stops working before it does anything.

- The colour card said only "saturation 20" when the gamma curve had been
  changed as well, which is the larger part of the difference.

### Changed

- *Read again* is a symbol instead of a button with a word on it.
- The Games cards drop the line under the percentage that said "small, but
  measurable". The number above it already said that.
