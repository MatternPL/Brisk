# Brisk 1.6.5

### New

- **`Brisk.exe` is published on its own,** next to the installer. It needs
  nothing installed, writes nothing outside its own folder and
  `%LOCALAPPDATA%\Brisk`, and runs from a USB stick. It is also the better
  download if your antivirus is nervous about self-extracting installers.

### Changed

- **Games says whether each setting is done.** Every card now reads *Optimised*
  or *Not optimised*, instead of a state line that told you what the setting was
  without answering whether you had changed it. The two buttons became one:
  *Optimise* or *Undo*, the same two words on every card. The explanations and
  costs are cut to one line each, and the grid lines up with the box above it.

### Fixed

- **A new release could be reported as "you have the latest version"** for the
  first few minutes after it was published. The version check now asks for a
  fresh copy rather than accepting a cached one.

- **The installer had no version information at all** — version `0.0.0.0`, no
  publisher, no product, no description. It was built without those attributes,
  so nothing was written into the file. An unsigned installer that unpacks an
  executable already looks unusual to antivirus heuristics; missing metadata is
  one more mark against it. It now carries a version, a publisher and a
  description.

  This does not make the false positives disappear on its own. A code signing
  certificate does, and that is the next step. Until then, the README explains
  what the detections are and what you can check for yourself.
