# Brisk 1.6.1

### Fixed

- **"Install selected" in Updates looked like it did nothing.** Every line of
  progress went to the single status line at the bottom of the window, so during
  a download that takes minutes it sat completely still — and if something failed,
  the message was overwritten a moment later by the summary.

  Updates now install one at a time, and each step is reported: which update,
  downloading, installing, done, or the exact code Windows refused it with. The
  page has its own output area so the lines stay readable. Pressing the button
  with nothing ticked, or without administrator, now says so plainly instead of
  in a status line you can miss.

- **The power plan in Games never actually changed.** It set a hardcoded GUID for
  Ultimate Performance, but Windows gives that scheme a new GUID every time it is
  duplicated — one machine here has two of them under different numbers — and on
  many machines, laptops especially, it does not exist at all. The change then
  failed silently.

  Brisk now reads the schemes that actually exist, picks one, creates Ultimate
  Performance by duplicating Microsoft's own if there is none, and checks
  afterwards that the scheme really became active. It recognises the plan by name
  as well as by GUID, since the name is translated to your system language.

### Changed

- Action tiles are slightly taller so their descriptions fit at narrow window
  sizes, the graphics card text stops before its button instead of running under
  it, and lists no longer show a horizontal scrollbar caused by rounding.
