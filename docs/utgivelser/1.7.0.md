# Brisk 1.7.0

### New

- **Brisk is signed.** Both the program and the installer carry a code signing
  certificate issued to Open Source Developer Mathias Arne Andresen. Windows
  shows that name where it used to say *Unknown publisher*, and anyone can
  check it themselves: right-click the file, Properties, Digital Signatures.
  The signature is timestamped, so it stays valid after the certificate
  expires.

  It does not make SmartScreen disappear overnight. Reputation is earned per
  certificate over downloads and time. What changes is that it now accumulates
  at all — before, every release started from zero, because an unsigned file
  is judged by its hash and each build has a new one.

- **Variable refresh rate, per screen.** The Screen page says whether a screen
  handles G-SYNC or FreeSync, and over what range. The answer is read from the
  screen's own EDID rather than from the graphics card, so it is the same
  information whether the machine has NVIDIA or AMD — NVIDIA calls it G-SYNC
  Compatible, AMD calls it FreeSync, but it comes from the same panel.

  Where a screen does not advertise it, Brisk says it was not reported rather
  than that it is unsupported. A screen that only announces variable refresh
  through the HDMI Forum block is not detected here, and claiming it cannot do
  it would be wrong.

- **Crash reports point at a line.** The symbol file now ships with the
  installation, so a stack trace names the file and line number instead of
  just the method. A bug report from someone else is worth something now.

### Changed

- **Colour is set per screen.** It used to apply to all of them at once. A
  curve that suits a large OLED is not necessarily right for a small screen
  beside it — and the saturation was only ever applied to the first screen
  anyway. Each screen now carries its own state and its own buttons, and Reset
  gives back exactly what that screen had before Brisk touched it.

- The publisher is now the name of the person behind Brisk, in the file
  properties and in Apps & Features, instead of the product name. It should be
  the same sender everywhere the signature is.

### Fixed

- **Upgrading from 1.6.6 with a colour profile applied left the screen dark.**
  The old settings said nothing about which screen had what, so the new
  per-screen code read Brisk's own earlier curve as "how the screen was to
  begin with" — and Reset would never have given the original back. The old
  curve is now restored before those settings are cleared.
