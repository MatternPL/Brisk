# Brisk 1.6.2

### New

- **Brisk measures your machine while it starts.** A start-up screen with a
  progress bar reads junk files, start-up programs, drive health and crashes
  before the window opens, so the front page has real numbers from the first
  moment instead of dashes until you press a button.

- **A graphics driver check that actually asks the manufacturer.** Updates now
  shows your card and the driver version the way NVIDIA and AMD write it
  themselves, not Windows' internal number, and can look up whether something
  newer exists. NVIDIA is asked through their own driver search; AMD through the
  version in the installer link on their download page. If there is a newer
  driver, Brisk downloads it to your Downloads folder — only over https from the
  manufacturer's own domain, and nowhere else. It does not run the installer: a
  driver install blanks the screen, and that is yours to start when you are ready.

- **Blue screens can be marked as seen.** The count comes from Windows' own
  crash dumps, so cleaning them away is not a way to hide a crash, and clearing
  the event log would take all your other history with it. Instead, Health has a
  Mark as seen tile: the number stays honest, but the front page stops flagging
  crashes you have already looked at.

### Changed

- **The front page is one box with nine fields.** Memory, free space, junk,
  start-up programs, drive wear, drive temperature, graphics driver, uptime, and
  whichever stability figure is real — blue screens if you have any, otherwise
  how many times a program crashed in the last month and which one does it most.

- **Brisk draws its own title bar,** with rounded corners like the rest of
  Windows 11. Dragging, snapping to the screen edges, double-click to maximize
  and resizing from the edges all still work.

- **The sidebar is grouped** into Space, Speed, Diagnostics and Update and fix,
  instead of twelve identical entries in a row.

- **Under 10 GB of junk is fine, and shows green.** The figure also stops
  counting the categories that are unticked in Cleanup — browser cache, crash
  dumps and Windows.old were never going to be deleted, so they should not make
  the number red. Cleaning now measures again instead of resetting to zero, so
  the front page is right when you only ticked some of the categories.

### Fixed

- Blue screens no longer appear in two different counts. The front page read the
  Windows event log while Health could only list crashes it had a dump file for,
  so the front page could claim a crash that Health had nothing to show for.
  Both now count dump files, and when there is nothing to show, neither mentions
  blue screens at all.

- The box on the front page stops in flush with the fields under it. Every cell
  carried the same right padding, including the last column, so the grid ended
  fourteen pixels short and looked misaligned.

- Games says when a change is waiting for a restart, instead of looking as
  though it did nothing.

- The window opens tall enough to show every card in full, and there is more air
  under the numbers and under the section headings.
