# Brisk 1.7.4

### Fixed

- **A downloaded AMD driver could not be run.** Double-clicking it did nothing,
  because it was never a program: AMD sends the direct download link on to a
  web page titled *Download Not Complete* whenever the request does not come
  from their own download page. Brisk saved that page to disk with `.exe` on
  the end. It now asks the way AMD expects, and the driver arrives as the
  47 MB installer it should be.

  NVIDIA was checked as well and was never affected — those links are served
  directly.

- **Brisk said "downloaded" whatever came back.** That is the reason nobody
  caught the problem above: the download reported success without ever looking
  at what it had written. Every Windows program starts with the same two
  letters, and Brisk now checks for them. If a file is not a program it is
  deleted and you are told to fetch the driver from the manufacturer's own
  site, rather than being left with something that does nothing when you open
  it. The check covers both manufacturers, so the next time one of them changes
  how downloads work, Brisk will say so instead of handing you a broken file.
